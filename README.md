# Colección de Figuritas 2026 - Android

Aplicación Android oficial del proyecto **Colección de Figuritas 2026**.

## Descripción

Esta aplicación permite gestionar una colección de figuritas desde dispositivos Android, ofreciendo una experiencia nativa para consultar y administrar la colección.

## Tecnologías

- Kotlin
- Android Studio
- Gradle
- Material Design

## Requisitos

- Android Studio (versión recomendada más reciente)
- JDK 17 o superior

## Cómo ejecutar el proyecto

1. Clonar el repositorio:

```bash
git clone <URL_DEL_REPOSITORIO>
```

2. Abrir el proyecto en Android Studio.

3. Esperar la sincronización de Gradle.

4. Ejecutar la aplicación en un emulador o dispositivo físico.
